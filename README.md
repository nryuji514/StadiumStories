# アプリ名
StadiumStories
## 概要
今回は下記の使用技術を使い、1人で要件定義、フロント・バックエンド・デプロイを行いました。 
趣味が野球観戦ということがあって初めて自分と同じように球場に足を運び、楽しみたいという人やこれから行ってみたいという人に対してより快適に球場まで足を運び、また試合の合間にブログ投稿ができるアプリを開発しました。
具体的にはGoogleMapApiを使用し、球場を保存し、さらに付近の駅名を入力することによって球場から駅までのルートを保存することができます。
またルートから半径500メートルの飲食店、コンビニエンスストア、スーパーマーケットを自動検索し、保存することができます。
球場内のフードやドリンクは値段が高いという懸念点があります。自分のようにあまりお金を使わずに楽しみたいという方は予め付近のお店で買い物をし、快適に観戦を楽しめるアプリとなっています。

## 機能
- 投稿周りのCRUD
- いいね機能
- コメント機能
- 画像投稿
- Map機能
- 二地点間の経路表示
- 経路から半径500メートル内の店舗表示
- ログイン機能
- プロフィール機能
  

## 工夫点
- 球場から最寄りの駅の二地点間の経路表示・保存をGoogleMapAPIを使用し、可能にしたところ
- 経路から半径500メートル内の飲食店、コンビニエンスストア、スーパーマーケットを分けて自動取得できるところ
- 自動取得した店舗に対し、野球ファン目線のお店選びや投稿を可能にした

## 苦労した点
- ルートに表示されている店舗ごとに対する投稿を可能にするためのリレーション
- 二地点間のルートを決めるためのデータベース設計
